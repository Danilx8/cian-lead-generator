# Cian Lead Generator

Система лидогенерации для недвижимости на Авито. Выполнил Луговских Данил Викторович

## Архитектура

- **src/** — основное приложение (Express API + Redis + PostgreSQL + K8s оркестрация)
- **job/** — микросервис-воркер (Puppeteer) для автоматизации работы с Цианом

## Стек

- Node.js + TypeScript
- Express (REST API + JWT авторизация)
- Sequelize + PostgreSQL
- Redis (pub/sub, кэширование)
- Kubernetes (K3s, оркестрация воркеров)
- Puppeteer (автоматизация браузера)

## Фильтры недвижимости

Поддерживаемые фильтры для Циана:

- **Тип сделки**: покупка, долгосрочная аренда, посуточная аренда
- **Тип недвижимости**: квартира, комната, дом/дача, земля, коммерция, гараж
- **Рынок**: вторичка, новостройка
- **Локация**: город/регион
- **Комнаты**: студия, 1, 2, 3, 4, 5+
- **Цена**: мин/макс
- **Площадь**: общая, кухня
- **Этаж**: мин/макс, этажность дома
- **Тип дома**: кирпич, панель, монолит, блок, дерево
- **Ремонт**: дизайнерский, евро, косметический, требуется
- **Продавец**: собственник, агент, застройщик
- **Дополнительно**: не первый/не последний этаж, с фото, ипотека

## Запуск

```bash
cp .env.example .env
# настройте .env

docker compose up -d
npm run db:init
npm run dev
```

## Сборка

```bash
npm run build
npm start
```
